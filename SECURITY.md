# Security policy

## Supported versions

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Please report security issues privately via GitHub
[Security Advisories](https://github.com/ababic/django-mirroring/security/advisories/new)
rather than opening a public issue.

Do not include production database credentials, Dumpling salts
(`DUMPLING_GLOBAL_SALT`), or customer/PII samples in reports.
